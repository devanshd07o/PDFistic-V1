Licensing Architecture & IP Boundaries

PDFistic operates under a clean dual-tier licensing model, establishing an explicit legal boundary between the proprietary desktop client and the permissive third-party runtime modules that power underlying document rendering:

Tier 01 — Proprietary Core

Closed-Source Application Shell

The PDFistic desktop client, window management, tab session persistence engine, stylus ink smoothing, custom themes, Zernexa AI prompt orchestration, and commercial product branding are proprietary software.

Copyright © 2026 Devansh Dubey · All Rights Reserved
Tier 02 — Runtime Dependencies

Third-Party Permissive Ecosystem

Low-level PDF rasterization, on-device WebAssembly OCR, scientific LaTeX formatting, interactive charts, and native desktop runtime bridges execute via battle-tested open-source libraries under permissive licenses.

Governed by Apache-2.0, MIT, BSD-3-Clause, and ISC Licenses
