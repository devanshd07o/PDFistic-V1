Executive Privacy Commitment

PDFistic is engineered from the ground up as a local-first, private desktop reader. Your documents, highlights, notes, and reading habits remain strictly on your personal computer by default. Devansh Dubey (the independent developer) does not operate cloud servers that store your documents, does not run background telemetry SDKs, does not collect analytics from within the desktop app, and never monetizes your reading data.

100% Offline-First Core

PDF decoding, book-flip simulation, canvas rendering, and Tesseract OCR run in-memory on your local CPU/GPU.

Zero Telemetry Inside App

No background tracking SDKs, no device fingerprinting, no usage metrics, and zero forced account registration.

Hardware-Bound DPAPI

AI API keys and OAuth tokens are encrypted at rest via Windows Data Protection API (DPAPI) and Electron SafeStorage.

Zero Intermediary Proxies

AI and Google Drive requests connect directly from your PC to official endpoints over TLS 1.3 with no developer middleman.

2. Local File Processing & Text Extraction Architecture

When you open a PDF or an EPUB document in PDFistic, the file is read from your local storage drive (NTFS/ReFS) into an isolated sandboxed Chromium renderer process on your Windows computer:

  • In-Memory Rendering: Document parsing, font rasterization, table-of-contents extraction, and canvas presentation are performed entirely locally using Mozilla PDF.js. No temporary unencrypted copies are uploaded to external rendering pipelines.
  • Annotations & Markups: When you highlight text, draw with digital ink, or attach sticky notes, annotations reside in volatile application memory during your active reading session. When you explicitly click Save or Export, changes are written directly into the local target file on your disk using client-side binary byte patching via pdf-lib.
  • Local WebAssembly OCR: Optical Character Recognition (OCR) for scanned PDFs and image-based book pages is powered by bundled WebAssembly (Wasm) builds of Tesseract.js. OCR executes 100% locally on your machine. PDFistic does not send your document pages or bitmap crops to third-party computer vision cloud APIs.

3. The Non-Collection Guarantee (What PDFistic NEVER Collects)

Unlike conventional SaaS document platforms that stream reading activity to cloud analytics services, the PDFistic desktop binary includes zero telemetry libraries. The table below outlines our non-collection policy:

Data Category Collected by Developer? Storage Location / Transmission Mechanism
Document Content & Text NEVER Resides strictly in your local PC RAM and local storage drive.
Document Paths & File Names NEVER Stored locally in %APPDATA%\PDFistic\config.json for recent files list.
Reading Time & Page Progress NEVER Stored locally in your Windows profile; optionally synced to your private Google Drive AppData folder if enabled.
Hardware / Device Fingerprints NEVER No hardware ID hashing or device profiling is executed.
In-App UI Click Telemetry NEVER No tracking SDKs (no Firebase, Mixpanel, Sentry, or Google Analytics) inside the desktop app.

Landing Website Disclosure: This marketing website (devanshd07o.github.io/PDFistic-V1) loads web fonts from Google Fonts and includes privacy-preserving Google Analytics 4 (GA4) with IP anonymization enabled (anonymize_ip: true) strictly to count aggregate page views. The website does not set cross-site tracking cookies.

4. Optional Google Sign-In & Drive Sync (Limited Use Compliance)

PDFistic provides an optional Google Sign-In feature that allows cross-device synchronization of reading progress, annotations, and cloud library documents. If you choose to authenticate with Google, authentication uses OAuth 2.0 with Proof Key for Code Exchange (PKCE, RFC 7636) directly on your local device:

Requested Google OAuth Scopes & Strict Purpose
  • Profile Identity (openid, email, profile): Used strictly to display your user name, email, and avatar in the local workspace greeting header.
  • Hidden Application Data (drive.appdata): Manages a single isolated file named pdfistic-sync-v1.json in your personal Google Drive hidden AppData folder. This file stores your per-book reading bookmarks, highlight coordinates, and UI settings. No other application or developer backend has access to this folder.
  • Dedicated Library Storage (drive.file): Grants access strictly to files you create, upload, or choose to open through PDFistic within your personal PDFistic Library Google Drive folder. PDFistic cannot browse, inspect, or modify other documents in your Drive.
Google API Services User Data Policy Compliance Statement:

PDFistic's use and transfer to any other app of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Specifically:

  • User data from Google APIs is never transferred or sold to third parties, data brokers, or advertising platforms.
  • Google user data is never used for serving advertisements or behavioral profiling.
  • Google user data is never used to train generalized artificial intelligence or machine learning models.
  • Humans are never permitted to read your synced document data unless you explicitly give consent for technical support or security investigations.

You can disconnect Google Drive at any time by clicking Sign Out in the in-app profile menu or revoking authorization in your Google Account Permissions Manager.

5. Bring-Your-Own-Key (BYOK) AI Copilot Security Architecture

PDFistic features an integrated AI copilot dock for document Q&A, summaries, and mathematical explanations. We mandate a strict Bring-Your-Own-Key (BYOK) architecture to maximize user privacy and prevent vendor lock-in:

Direct Point-to-Point TLS 1.3

When you submit a prompt, PDFistic constructs a direct encrypted HTTPS payload containing your query and selected context excerpts. This request is transmitted straight from your PC to the official API endpoint of your chosen provider.

Endpoints: generativelanguage.googleapis.com • api.groq.com • api.anthropic.com • api.openai.com • openrouter.ai

Windows DPAPI Local Encryption

Your third-party API keys are never stored in plaintext. They are encrypted on disk via Electron SafeStorage using the Windows Data Protection API (DPAPI). The encryption key is cryptographically tied to your specific Windows user profile credentials.

Algorithm: CryptProtectData (DPAPI) + AES-GCM local authenticated storage

Zero Developer Middleman: Devansh Dubey does not run an intermediate proxy, backend API server, or logging cache. Because requests flow directly between your machine and your provider, your provider's respective privacy policy, data retention schedules, and model training terms govern your AI prompts:

  • Google Gemini Privacy Terms
  • Groq Cloud Data Privacy Policy
  • Anthropic Privacy Statement
  • OpenAI Privacy Policy
  • OpenRouter Privacy Policy

6. Voice Input & Audio Processing

PDFistic provides an optional voice input feature for speech-to-text dictation into the AI prompt bar:

  • Default Inactive State: The microphone is disabled by default. The application only accesses your audio hardware when you explicitly click the microphone icon.
  • Speech Recognition Pipeline: Audio is processed via the standard Chromium Web Speech API embedded in the Electron framework. In standard Windows environments, speech audio is streamed to Google's speech recognition servers to convert spoken audio into text.
  • Zero Audio Storage by Developer: PDFistic does not record, retain, process, or store microphone audio on developer infrastructure.
  • OS Permission Control: You can inspect or revoke PDFistic's microphone privileges at any time in Windows Settings: Settings → Privacy & security → Microphone.

7. Local System Footprint & Permanent Data Erasure

PDFistic stores all application settings, window positions, book flip caches, and DPAPI-encrypted API keys locally in standard Windows user profile directories:

Data Asset Exact Windows File System Location Encryption / Security State
User Preferences & Config %APPDATA%\PDFistic\config.json Plaintext JSON for UI settings; API keys and OAuth tokens encrypted via DPAPI.
Diagnostic Runtime Logs %APPDATA%\PDFistic\logs\main.log Local rotating text logs; strictly captures startup diagnostics and crashes. Never auto-uploaded.
Offline Document Caches %APPDATA%\PDFistic\Partitions\ Chromium sandboxed IndexedDB and CacheStorage for page thumbnails and EPUB chapters.

How to Permanently Erase All Data

You maintain 100% autonomous control over your local data footprint. You can delete all traces using any of the following methods:

  1. In-App Reset (Instant): Navigate to Settings → Privacy & Data → Clear All App Data to wipe stored API keys, recent document history, and local caches immediately.
  2. Manual File Explorer Purge: Close PDFistic, press Win + R, type %APPDATA%, and permanently delete the PDFistic directory.
  3. Clean App Uninstallation: Uninstalling PDFistic via Windows Settings → Apps → Installed apps removes the application executable. Deleting the %APPDATA%\PDFistic folder removes all remaining configuration files.

8. International Privacy Compliance & Regulatory Rights

PDFistic was architected from inception to exceed international data privacy requirements under global frameworks, including the European Union General Data Protection Regulation (GDPR) and the California Consumer Privacy Act (CCPA/CPRA):

GDPR Compliance (EU Users)

Under GDPR Articles 15 through 22, users hold fundamental rights of access, rectification, portability, and erasure. Because PDFistic stores your documents and data locally on your personal device, you possess total autonomous control over your data without submitting a Subject Access Request (SAR).

CCPA / CPRA Notice (California Users)

PDFistic does not sell, share, or monetize personal information. We do not participate in cross-context behavioral advertising, data brokerage, or consumer profiling. Your reading habits are never commercialized.

Children's Online Privacy Protection Act (COPPA): PDFistic does not knowingly collect, transmit, or solicit personal information from children under 13. The application operates offline and requires no age-gated registration.

9. Software Distribution, Store Certification & Telemetry

PDFistic is distributed through two official, signed channels:

  • Microsoft Store (MSIX Package): Updates are distributed securely through the Windows Store infrastructure in compliance with Microsoft Store Policy Section 10.5 (Personal Information). Microsoft provides registered publishers with aggregated, anonymized analytical telemetry via Partner Center (such as total installs by country and crash stack traces). These reports contain zero document contents, personal identities, or IP addresses.
  • GitHub Releases (Open Source Standalone): The open-source release checks the public GitHub REST API (api.github.com) to notify you when a newer version is published. Standard GitHub privacy policies govern these public metadata requests.
