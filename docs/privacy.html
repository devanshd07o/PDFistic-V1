Privacy Policy

How PDFistic handles your files, optional AI features, and local settings.

Last updated November 10, 2026 · Version 2.0.0

In short

PDFistic runs on your Windows PC. Your documents stay on your computer unless you explicitly choose to send text to an AI service that you configured, or use optional voice input (see "Voice input" below). I do not run analytics, I do not track what you read, and I do not have a server that collects your personal data.

No analytics or ads

No tracking SDKs, no telemetry, no account.

Files stay local

PDF rendering, annotations and OCR run on your PC.

Encrypted API keys

Your AI API keys are encrypted with Windows DPAPI and tied to your Windows account.

What the app does with your files

When you open a PDF or an EPUB file in PDFistic, the app reads the file from your local disk into memory. Rendering, page-flipping, text search, bookmarks, and annotations run directly on your computer using local code.

When you draw on a page, add highlighters, or place sticky notes, these edits stay in your local session. When you click Save or Export, the app writes those annotations directly into the file on your disk.

The built-in text recognition (OCR) feature runs locally using bundled language models on your PC. It does not download language data from a content delivery network at runtime, and it does not send your document pages or images to an external vision service.

What I don't collect

I built PDFistic as a straightforward desktop tool. The application does not contain analytics SDKs, advertising trackers, or telemetry libraries. The only network requests it makes are the optional ones described on this page: AI requests you trigger, voice input you trigger, and update checks.

  • Your documents: I do not receive your file names, contents, paths, reading progress, or annotations.
  • Your usage habits: I do not track which buttons you click, how long you read, or when you launch the application.
  • Personal details: You do not need to create an account, register an email address, or sign in to use PDFistic.

This website does not set tracking cookies. The website loads web fonts from Google Fonts (fonts.googleapis.com), which receives standard browser request headers when downloading font files.

AI features (optional) and your API keys

PDFistic includes optional AI assistance for asking questions about your reading. You do not need to use this feature. The rest of the app works without entering any API key.

If you choose to use the AI dock, you provide your own API key for the provider you prefer (such as Google Gemini, Groq, Anthropic, OpenAI, or OpenRouter).

Your API keys are encrypted on disk using the Windows Data Protection API (DPAPI via Electron SafeStorage). DPAPI ties the encryption key to your current Windows user account, which protects the keys if someone copies the configuration file without logging into your Windows profile.

When you send a question or ask about an excerpt, PDFistic makes a direct HTTPS call from your computer to the official endpoint of the provider you configured. This request contains your question, the relevant excerpts of your document that PDFistic selects as context, and a compressed summary of your recent conversation. Nothing is sent until you submit a question.

  • Google Gemini: generativelanguage.googleapis.com (Google Privacy Policy)
  • Groq: api.groq.com (Groq Privacy Policy)
  • Anthropic: api.anthropic.com (Anthropic Privacy Policy)
  • OpenAI: api.openai.com (OpenAI Privacy Policy)
  • OpenRouter: openrouter.ai (OpenRouter Privacy Policy)

I do not run an intermediate proxy or gateway server. The text you choose to send goes directly from your PC to the provider you set up. Their own privacy policies, data retention terms, and model-training rules apply to those requests, not mine.

Do not send documents you are not allowed to share with a third party. AI responses can be wrong, so verify anything important. Any usage charges from your provider are between you and that provider.

Voice input

PDFistic has an optional voice input button. It is off until you click it. When you use it, your microphone audio is captured and processed by the browser speech recognition service built into the Chromium engine that PDFistic runs on. This is the Web Speech API, and it typically sends your audio to Google's speech servers to convert it to text. PDFistic does not record, store, or receive this audio, and I never see it. Google's own privacy policy and terms apply to that audio.

If you do not want audio to leave your PC, do not use voice input; the rest of the app works without it. Windows will ask for microphone permission, and you can revoke it anytime in Windows Settings → Privacy & security → Microphone.

Where data is stored and how to delete it

All application data is saved locally on your Windows PC in standard user directories:

What Where
Settings and encrypted keys %APPDATA%\PDFistic\config.json
Diagnostic logs %APPDATA%\PDFistic\logs\main.log Errors and startup diagnostics are written to your PC and are never uploaded automatically.
Session state and chat history Chromium storage inside %APPDATA%\PDFistic

You can remove your stored data at any time:

  • Inside PDFistic, open Settings → General and click Reset Workspace to clear your recent file list, saved chat messages, and local preferences.
  • To delete everything manually, close the app and remove the folder at %APPDATA%\PDFistic in Windows File Explorer.
  • Uninstalling PDFistic through Windows Settings removes the application files. You can delete the %APPDATA%\PDFistic folder afterwards to clear any remaining local settings.

PDFistic keeps no copy of your files. When you Save or Export, annotations are written into the file on your disk, so keep a backup if the original matters to you.

Updates and the Microsoft Store

If you downloaded PDFistic from the Microsoft Store, application updates are managed through the Windows Store client.

Microsoft provides registered publishers with aggregated, anonymous reports in the Microsoft Partner Center. These reports show aggregate download counts, country breakdown, and crash stack traces. I cannot identify you, your files, or your individual computer from these reports.

If you installed the standalone release from GitHub, the app checks the public GitHub releases feed to see if an update is available. Standard GitHub network logs apply to those requests.

Changes to this policy

If I update this policy, I will post the revision on this page and update the "Last updated" date at the top. If a future change alters how network requests or file data are handled, I will outline the details in the application release notes.
