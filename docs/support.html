In short

PDFistic runs on your PC and works out of the box without an account or an internet connection. If something does not work as expected or you have questions, reach me directly on GitHub or by email.

Getting started

Drag and drop any PDF or EPUB directly into PDFistic, or press Ctrl + O to open a file. The document opens directly in memory on your PC.

  • Document tabs: Open multiple documents in separate tabs, each with independent zoom, page state, and navigation history.
  • Recent files: The launchpad remembers your recent files locally so you can resume where you left off.
  • Offline by default: You do not need to configure keys, create an account, or connect to the internet to read and annotate files.

Setting default reader on Windows 11

To make PDFistic your primary PDF reader on Windows 11 so that double-clicking any PDF opens it directly:

  1. Right-click any PDF

    Right-click any .pdf file inside Windows File Explorer.

  2. Choose PDFistic

    Click Open with → Choose another app and pick PDFistic.

  3. Lock as default

    Check “Always use this app to open .pdf files” and click OK.

Alternatively, open Windows Settings (Win + I), go to Apps → Default apps, search for PDFistic, and select it for the .pdf extension.

Reader modes

PDFistic includes two reading engines designed for different types of reading:

  • Continuous scroll mode: Vertical scrolling designed for research papers, documentation, and technical reports. Supports text selection, line-by-line highlighting, freehand pen notes, and shape callouts.
  • 3D book-flip mode: Realistic page-turn simulation with two-page spread viewing and natural transitions, well-suited for novels and EPUB books.

Free AI keys guide

The optional AI Copilot can answer questions about your documents, summarize text, or explain complex passages. You can use free API keys from Google or Groq:

  • Google Gemini: Visit aistudio.google.com/app/apikey, sign in with your Google account, click Create API Key, and copy the key.
  • Groq Cloud: Visit console.groq.com/keys, create a free account, click Create API Key, and copy the key.
  • Saving your key in PDFistic: Press Ctrl + , to open Settings, go to AI & Keys, and paste your key. On Windows, keys are encrypted using Windows Data Protection API (DPAPI) and tied to your Windows user account.
Settings window with Appearance themes, Typography controls, and the AI & Keys tab for Windows DPAPI-protected keys.

Frequently asked questions

Does PDFistic require an internet connection?
No. All document rendering, EPUB parsing, text selection, annotations, and OCR run locally on your PC. An internet connection is only used if you opt in to Google Drive Sync or ask questions through the AI Copilot with your own API key.
What does signing in with Google do?
Signing in with Google is completely optional. When connected, PDFistic syncs your per-document annotations, bookmarks, reading progress, and preferences in your private Google Drive AppData folder (drive.appdata), and unlocks saving/opening files from a dedicated PDFistic Library folder (drive.file) on your Google Drive.
How do updates work?
If you installed PDFistic from the Microsoft Store, Windows handles updates automatically in the background. If you downloaded a standalone installer, updates are delivered from GitHub releases and can be installed directly from the in-app update prompt.
Are annotations saved directly into my files?
Your active annotations and reading positions are cached locally per document automatically (and synced across PCs if Google Drive Sync is enabled). When you click Save or Export, your highlights, notes, signatures, and drawings are embedded into the PDF file stream in accordance with ISO specifications.
How do I delete all data stored by the app?
Open Settings → Privacy & Data to clear saved chats, API keys, or cached annotations, or delete %APPDATA%\PDFistic on disk (or the package data folder under %LOCALAPPDATA%\Packages for Microsoft Store installs).
