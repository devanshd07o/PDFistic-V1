# Contributing to PDFistic

Thank you for your interest in improving PDFistic!

---

## Proprietary Software Model

PDFistic is commercial, proprietary desktop software authored by **Devansh Dubey** (Copyright © 2026 Devansh Dubey. All Rights Reserved.). 

The core application source code and desktop shell are closed-source. As such:
- **Code Pull Requests:** We do not accept unsolicited external code pull requests for the core PDFistic desktop application.
- **Community Engagement:** We enthusiastically welcome community participation through **bug reports**, **feature suggestions**, **workflow feedback**, and **documentation improvements**.

---

## How You Can Contribute

### 1. Reporting Bugs
Encountering a rendering bug, crashed document, or broken UI element?
- Search existing [GitHub Issues](https://github.com/devanshd07o/PDFistic-V1/issues) to verify if the issue has already been reported.
- If not, open a new issue using our **Bug Report Template**.
- Provide your Windows version, PDFistic build number, and if possible, non-sensitive sample files or screenshots demonstrating the failure.

### 2. Suggesting Features & Enhancements
Have an idea for a new reading tool, annotation feature, theme, or AI copilot workflow?
- Open a feature request via [GitHub Issues](https://github.com/devanshd07o/PDFistic-V1/issues/new) using our **Feature Request Template**.
- Explain the real-world reading or study use-case and why it adds value to the PDFistic experience.

### 3. Website & Documentation Feedback
If you notice typos, broken links, or formatting issues on our website (https://devanshd07o.github.io/PDFistic-V1/) or in our user documentation:
- Feel free to open an issue or submit a pull request against the `docs/` or documentation files in this repository.

### 4. Security Vulnerabilities
Please do **not** post security vulnerabilities publicly. Follow the guidelines in [SECURITY.md](SECURITY.md) and report directly to `devanshd07o@gmail.com`.
